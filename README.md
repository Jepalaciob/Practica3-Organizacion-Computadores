## Descripción

Este repositorio contiene la solución de la Práctica 3 del curso de
Organización y Arquitectura de Computadores. La práctica comprende un
ensamblador y un desensamblador para la plataforma Hack, basados en el
Proyecto 6 de Nand2Tetris.

El ensamblador traduce archivos `.asm` a código de máquina `.hack`. El
desensamblador realiza la traducción inversa y genera etiquetas para los
destinos de salto que pueden identificarse en el código binario.
